# Задача 5. Сумма элементов на чётных позициях

Идея: Начинаем с индекса 0 и переходим через один элемент. Сумма хранится в long,
поскольку сумма двух допустимых int уже может не помещаться в int.

Время: O(n): ceil(n / 2) сложений.

Дополнительная память: O(1).

Пример: [1, 100, 2, 100, 3] → 6. Проверяется чётность индексов, а не самих чисел.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_5.EvenIndexSum
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
