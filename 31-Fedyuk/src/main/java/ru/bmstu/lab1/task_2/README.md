# Задача 2. Индекс первого вхождения

Идея: Проверяем элементы по порядку индексов. Как только найдено значение x, возвращаем индекс.
Если проход закончился без совпадений, возвращаем -1.

Время: O(n) в худшем случае.

Дополнительная память: O(1).

Пример: [3, 8, 3, 8, 2], x = 3 → 0. Повтор в позиции 2 не должен заменять первое совпадение.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_2.FirstOccurrence
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
