# Задача 36. Бегущая сумма

Идея: При проходе поддерживаем сумму уже просмотренных значений. На каждой позиции
записываем её в новый массив long. Исходный массив сохраняется.

Время: O(n).

Дополнительная память: O(n) для результата.

Пример: [-2, 5, -7] → [-2, 3, -4]. Для [2147483647, 2147483647] результат
[2147483647, 4294967294], что проверяет разрядность промежуточных сумм.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_36.RunningSum
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
