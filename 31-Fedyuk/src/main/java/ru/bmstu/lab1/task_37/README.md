# Задача 37. Разворот массива

Идея: Используем два индекса на краях массива. Обмениваем их элементы и сдвигаем
индексы к центру. Изменяется переданный массив, новый массив не выделяется.

Время: O(n): floor(n / 2) обменов.

Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5] → [5, 4, 3, 2, 1]. Средний элемент остаётся на месте.
Повторный разворот восстанавливает исходный порядок.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_37.ArrayReverse
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
