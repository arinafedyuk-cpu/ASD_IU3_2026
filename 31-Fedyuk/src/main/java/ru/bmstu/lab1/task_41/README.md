# Задача 41. Удаление элемента

Идея: Сначала считаем элементы, не равные x, и выделяем массив нужной длины.
Во втором проходе записываем в него оставшиеся элементы в исходном порядке.
Исходный массив не изменяется; выполнение на месте в этой задаче не требуется.

Время: O(n): два прохода.

Дополнительная память: O(n) в худшем случае для результата.

Пример: [2, 1, 2, 3, 2], x = 2 → [1, 3]. Если удалить 7 из [7, 7], результат пустой
и выводится пустая строка. Проверяется удаление всех совпадений.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_41.RemoveElement
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
