# Задача 6. Элементы больше среднего

Идея: Первым проходом находим сумму в long и делим её на длину массива. Деление точное
по гарантии условия. Вторым проходом считаем значения строго больше полученного среднего.

Время: O(n): два линейных прохода.

Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5] → 2. Среднее равно 3, поэтому сам элемент 3 не учитывается.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_6.AboveAverageCount
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
По условию сумма должна делиться на n; эта гарантия входных данных сохраняется.
