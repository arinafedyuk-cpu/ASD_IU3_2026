# Задача 9. Проверка отсортированности

Идея: Проверяем, не меньше ли очередной элемент предыдущего. Если такое нарушение найдено,
возвращаем NO. Если весь массив прошёл проверку, возвращаем YES.

Время: O(n) в худшем случае.

Дополнительная память: O(1).

Пример: [-2, -2, 0, 3, 3] → YES; [1, 3, 2] → NO. Одинаковые соседи разрешены.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_9.SortedCheck
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
