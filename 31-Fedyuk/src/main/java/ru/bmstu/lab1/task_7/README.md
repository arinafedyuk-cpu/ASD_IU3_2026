# Задача 7. Второй максимум

Идея: Из первых двух элементов определяем максимум и второй максимум. При новом максимуме
прежний максимум становится вторым. В остальных случаях обновляем только второй максимум.
Используется гарантия условия, что все элементы различны.

Время: O(n).

Дополнительная память: O(1).

Пример: [-8, -3, -5, -10] → -5. Пример проверяет, что начальные значения не взяты равными нулю.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_7.SecondMaximum
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
По условию все элементы должны быть различны; эта гарантия входных данных сохраняется.
