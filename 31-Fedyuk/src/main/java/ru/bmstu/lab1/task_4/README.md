# Задача 4. Все индексы элемента

Идея: Записываем индексы совпадений в буфер. После прохода создаём массив только из заполненной
части. Индексы уже возрастают, так как исходный массив просматривается слева направо.

Время: O(n), включая копирование результата.

Дополнительная память: O(n).

Пример: [2, 7, 2, 3, 2], x = 2 → 0 2 4. При отсутствии x выводится пустая строка.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_4.AllIndices
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
