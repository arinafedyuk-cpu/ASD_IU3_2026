# Задача 8. Фильтрация по знаку

Идея: Положительные и отрицательные значения записываем в разные буферы. Нули пропускаем.
Копируем заполненные части в результат, сохраняя исходный порядок в каждой группе.

Время: O(n).

Дополнительная память: O(n).

Пример: [0, -2, 4, -1, 0, 3, -7] → положительные [4, 3], отрицательные [-2, -1, -7].
Группы выводятся на двух строках. Для [0, 0] обе строки пустые.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_8.SignFilter
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
