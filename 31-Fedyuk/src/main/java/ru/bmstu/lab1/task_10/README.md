# Задача 10. Поиск элемента с условием

Идея: Просматриваем массив справа налево до первого элемента с нулевым остатком от деления
на k. Его индекс будет последним подходящим индексом. Если совпадений нет, ответ -1.

Время: O(n) в худшем случае.

Дополнительная память: O(1).

Пример: [-6, 5, 0, 7], k = -3 → 2. Ноль кратен любому ненулевому k. Для k = 0
предусмотрена явная ошибка: это значение запрещено условием.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_10.LastMultiple
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
