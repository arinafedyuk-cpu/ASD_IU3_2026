# Задача 11. Ближайший к среднему

Идея: Сначала вычисляем сумму. Вместо дробных расстояний сравниваем |a[i] × n − sum|.
Умножение на положительное n сохраняет порядок расстояний. Меняем ответ только
при строгом улучшении, поэтому при равенстве остаётся первый элемент.

Время: O(n).

Дополнительная память: O(1). Все вычисления расстояний выполняются в long.

Пример: [1, 0] → 1: среднее 0,5, расстояния одинаковые, выбирается первый элемент.
Для [1, 4, 8] ответ 4. Выводится значение, а не индекс.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_11.ClosestToAverage
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
