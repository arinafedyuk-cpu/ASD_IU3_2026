# Задача 1. Максимум и минимум

Идея: Начинаем с первого значения массива и запоминаем текущие минимум и максимум.
Каждый следующий элемент сравнивается с ними. Ноль как начальное значение не используется,
поэтому полностью отрицательные массивы обрабатываются правильно.

Время: O(n): один проход.

Дополнительная память: O(1).

Пример: [3, -1, 9, 0, 4] → минимум -1, максимум 9. Для [-3, -9, -5] ответ -9 и -3.
Проверяется работа с отрицательными значениями.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_1.MinMax
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
