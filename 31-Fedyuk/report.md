Дополнительные задачи 25, 26, 36, 37, 38, 41: 6 × 2 = 12 баллов.

Решения находятся в отдельных пакетах `ru.bmstu.lab1.task_<номер>`.
В каждом пакете есть README с краткой идеей, временем и памятью.
Классы названы по назначению: MinMax, FirstOccurrence, LeftRotation и другие;
полный список со ссылками приведён в README модуля.
Используются обычные массивы. Общие операции ввода и вывода вынесены в `ConsoleIo`,
разворот участка массива — в `ArrayReversal`.

Ввод: n, затем n целых чисел. В задачах 2, 3, 4 и 41 после массива вводится x,
в задачах 10 и 38 — k, в задаче 12 — s. Программа печатает подсказки и результат.
Неверный размер, нечисловое или недостающее значение и нулевой делитель
обрабатываются с сообщением «Ошибка» без вывода стека исключения.
Во всех выбранных задачах 2 ≤ n ≤ 99999. Элементы массива имеют тип int.
Дополнительная память ниже указана без входного массива, но с учётом результата.

## Задача 1. Максимум и минимум

Начинаем с первого значения массива и запоминаем текущие минимум и максимум.
Каждый следующий элемент сравнивается с ними. Ноль как начальное значение не используется,
поэтому полностью отрицательные массивы обрабатываются правильно.

Время: O(n): один проход. Дополнительная память: O(1).

Пример: [3, -1, 9, 0, 4] → минимум -1, максимум 9. Для [-3, -9, -5] ответ -9 и -3.
Проверяется работа с отрицательными значениями.

## Задача 2. Индекс первого вхождения

Проверяем элементы по порядку индексов. Как только найдено значение x, возвращаем индекс.
Если проход закончился без совпадений, возвращаем -1.

Время: O(n) в худшем случае. Дополнительная память: O(1).

Пример: [3, 8, 3, 8, 2], x = 3 → 0. Повтор в позиции 2 не должен заменять первое совпадение.

## Задача 3. Подсчёт вхождений

Для каждого совпадения с x добавляем единицу к счётчику. Просматриваем весь массив,
поскольку подходящие значения могут находиться и в самом конце.

Время: O(n). Дополнительная память: O(1).

Пример: [1, 2, 1, 3, 1], x = 1 → 3. Если x = 7, ответ 0.

## Задача 4. Все индексы элемента

Записываем индексы совпадений в буфер. После прохода создаём массив только из заполненной
части. Индексы уже возрастают, так как исходный массив просматривается слева направо.

Время: O(n), включая копирование результата. Дополнительная память: O(n).

Пример: [2, 7, 2, 3, 2], x = 2 → 0 2 4. При отсутствии x выводится пустая строка.

## Задача 5. Сумма элементов на чётных позициях

Начинаем с индекса 0 и переходим через один элемент. Сумма хранится в long,
поскольку сумма двух допустимых int уже может не помещаться в int.

Время: O(n): ceil(n / 2) сложений. Дополнительная память: O(1).

Пример: [1, 100, 2, 100, 3] → 6. Проверяется чётность индексов, а не самих чисел.

## Задача 6. Элементы больше среднего

Первым проходом находим сумму в long и делим её на длину массива. Деление точное
по гарантии условия. Вторым проходом считаем значения строго больше полученного среднего.

Время: O(n): два линейных прохода. Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5] → 2. Среднее равно 3, поэтому сам элемент 3 не учитывается.

## Задача 7. Второй максимум

Из первых двух элементов определяем максимум и второй максимум. При новом максимуме
прежний максимум становится вторым. В остальных случаях обновляем только второй максимум.
Используется гарантия условия, что все элементы различны.

Время: O(n). Дополнительная память: O(1).

Пример: [-8, -3, -5, -10] → -5. Пример проверяет, что начальные значения не взяты равными нулю.

## Задача 8. Фильтрация по знаку

Положительные и отрицательные значения записываем в разные буферы. Нули пропускаем.
Копируем заполненные части в результат, сохраняя исходный порядок в каждой группе.

Время: O(n). Дополнительная память: O(n).

Пример: [0, -2, 4, -1, 0, 3, -7] → положительные [4, 3], отрицательные [-2, -1, -7].
Группы выводятся на двух строках. Для [0, 0] обе строки пустые.

## Задача 9. Проверка отсортированности

Проверяем, не меньше ли очередной элемент предыдущего. Если такое нарушение найдено,
возвращаем NO. Если весь массив прошёл проверку, возвращаем YES.

Время: O(n) в худшем случае. Дополнительная память: O(1).

Пример: [-2, -2, 0, 3, 3] → YES; [1, 3, 2] → NO. Одинаковые соседи разрешены.

## Задача 10. Поиск элемента с условием

Просматриваем массив справа налево до первого элемента с нулевым остатком от деления
на k. Его индекс будет последним подходящим индексом. Если совпадений нет, ответ -1.

Время: O(n) в худшем случае. Дополнительная память: O(1).

Пример: [-6, 5, 0, 7], k = -3 → 2. Ноль кратен любому ненулевому k. Для k = 0
предусмотрена явная ошибка: это значение запрещено условием.

## Задача 11. Ближайший к среднему

Сначала вычисляем сумму. Вместо дробных расстояний сравниваем |a[i] × n − sum|.
Умножение на положительное n сохраняет порядок расстояний. Меняем ответ только
при строгом улучшении, поэтому при равенстве остаётся первый элемент.

Время: O(n). Дополнительная память: O(1). Все вычисления расстояний выполняются в long.

Пример: [1, 0] → 1: среднее 0,5, расстояния одинаковые, выбирается первый элемент.
Для [1, 4, 8] ответ 4. Выводится значение, а не индекс.

## Задача 12. Пара с заданной суммой

Создаём записи со значением и исходным индексом. Сортируем их по значению, затем
по индексу. Для каждого i двоичным поиском ищем первую запись не меньше
(s − a[i], i + 1). Совпадение значения даёт минимальный подходящий j для этого i.
Перебор i по возрастанию обеспечивает минимальный первый индекс.

Время: O(n log n): сортировка и до n двоичных поисков. Дополнительная память: O(n).

Пример: [1, 2, 3, 4], s = 5 → 0 3, хотя существует пара 1 2. Для [1, 2, 4], s = 8
ответ -1 -1: один элемент нельзя использовать дважды.

## Задача 25. Сумма элементов

Складываем все значения массива в переменную типа long. Для допустимого размера
массива этого типа достаточно даже при крайних значениях int.

Время: O(n), один проход. Дополнительная память: O(1).

Пример: [1, -2, 3, 0, 5] → 7. Для [2147483647, 2147483647] ответ 4294967294:
проверяется отсутствие переполнения int.

## Задача 26. Произведение элементов

После каждого умножения берём остаток по модулю M = 1000000007. Отрицательное
значение сначала приводится к остатку от 0 до M − 1. Оба множителя меньше M,
поэтому промежуточное произведение помещается в long.

Время: O(n), один проход. Дополнительная память: O(1).

Пример: [2, 3, 4, 5] → 120. Для [-2, 3] ответ 1000000001, для [-2, -3] — 6.
Проверяется правильный неотрицательный остаток при разных знаках.

## Задача 36. Бегущая сумма

При проходе поддерживаем сумму уже просмотренных значений. На каждой позиции
записываем её в новый массив long. Исходный массив сохраняется.

Время: O(n). Дополнительная память: O(n) для результата.

Пример: [-2, 5, -7] → [-2, 3, -4]. Для [2147483647, 2147483647] результат
[2147483647, 4294967294], что проверяет разрядность промежуточных сумм.

## Задача 37. Разворот массива

Используем два индекса на краях массива. Обмениваем их элементы и сдвигаем
индексы к центру. Изменяется переданный массив, новый массив не выделяется.

Время: O(n): floor(n / 2) обменов. Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5] → [5, 4, 3, 2, 1]. Средний элемент остаётся на месте.
Повторный разворот восстанавливает исходный порядок.

## Задача 38. Циклический сдвиг влево

Сокращаем k по длине массива. Разделяем массив на первые k элементов A и остаток B.
Разворачиваем A, затем B, затем весь массив: получается B + A.
Общий метод разворота используется также в задаче 37. При нулевом сдвиге ничего
не меняем. Отрицательный k дополнительно поддерживается как сдвиг вправо.

Время: O(n): три разворота. Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5], k = 7 → [3, 4, 5, 1, 2]. Полные обороты отбрасываются.
Для k = 0 и k = n исходный массив сохраняется.

## Задача 41. Удаление элемента

Сначала считаем элементы, не равные x, и выделяем массив нужной длины.
Во втором проходе записываем в него оставшиеся элементы в исходном порядке.
Исходный массив не изменяется; выполнение на месте в этой задаче не требуется.

Время: O(n): два прохода. Дополнительная память: O(n) в худшем случае для результата.

Пример: [2, 1, 2, 3, 2], x = 2 → [1, 3]. Если удалить 7 из [7, 7], результат пустой
и выводится пустая строка. Проверяется удаление всех совпадений.
