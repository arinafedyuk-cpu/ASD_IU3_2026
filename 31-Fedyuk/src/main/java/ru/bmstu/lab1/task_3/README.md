# Задача 3. Подсчёт вхождений

Идея: Для каждого совпадения с x добавляем единицу к счётчику. Просматриваем весь массив,
поскольку подходящие значения могут находиться и в самом конце.

Время: O(n).

Дополнительная память: O(1).

Пример: [1, 2, 1, 3, 1], x = 1 → 3. Если x = 7, ответ 0.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_3.OccurrenceCount
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
