# Задача 26. Произведение элементов

Идея: После каждого умножения берём остаток по модулю M = 1000000007. Отрицательное
значение сначала приводится к остатку от 0 до M − 1. Оба множителя меньше M,
поэтому промежуточное произведение помещается в long.

Время: O(n), один проход.

Дополнительная память: O(1).

Пример: [2, 3, 4, 5] → 120. Для [-2, 3] ответ 1000000001, для [-2, -3] — 6.
Проверяется правильный неотрицательный остаток при разных знаках.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_26.ModularProduct
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
