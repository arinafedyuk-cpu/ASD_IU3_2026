# Задача 12. Пара с заданной суммой

Идея: создаём записи со значением и исходным индексом. Сортируем их по значению, затем
по индексу. Для каждого i двоичным поиском ищем первую запись не меньше
(s − a[i], i + 1). Совпадение значения даёт минимальный подходящий j для этого i.
Перебор i по возрастанию обеспечивает минимальный первый индекс.

Время: O(n log n): сортировка и до n двоичных поисков.

Дополнительная память: O(n).

Пример: [1, 2, 3, 4], s = 5 → 0 3, хотя существует пара 1 2. Для [1, 2, 4], s = 8
ответ -1 -1: один элемент нельзя использовать дважды.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_12.PairWithSum
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
