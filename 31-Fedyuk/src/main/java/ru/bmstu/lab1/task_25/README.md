# Задача 25. Сумма элементов

Идея: Складываем все значения массива в переменную типа long. Для допустимого размера
массива этого типа достаточно даже при крайних значениях int.

Время: O(n), один проход.

Дополнительная память: O(1).

Пример: [1, -2, 3, 0, 5] → 7. Для [2147483647, 2147483647] ответ 4294967294:
проверяется отсутствие переполнения int.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_25.ArraySum
```

Программа запрашивает длину и элементы массива; неверный размер, пропущенное или нечисловое значение
сопровождается сообщением «Ошибка».
