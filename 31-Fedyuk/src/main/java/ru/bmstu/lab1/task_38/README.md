# Задача 38. Циклический сдвиг влево

Идея: Сокращаем k по длине массива. Разделяем массив на первые k элементов A и остаток B.
Разворачиваем A, затем B, затем весь массив: получается B + A.
Общий метод разворота используется также в задаче 37. При нулевом сдвиге ничего
не меняем. Отрицательный k дополнительно поддерживается как сдвиг вправо.

Время: O(n): три разворота.

Дополнительная память: O(1).

Пример: [1, 2, 3, 4, 5], k = 7 → [3, 4, 5, 1, 2]. Полные обороты отбрасываются.
Для k = 0 и k = n исходный массив сохраняется.

Память всей программы с хранением входного массива: O(n).

Запуск из папки `31-Fedyuk` после сборки:

```sh
java -cp target/classes ru.bmstu.lab1.task_38.LeftRotation
```

Программа запрашивает длину и элементы массива, затем дополнительный параметр; неверный размер,
пропущенное или нечисловое значение сопровождается сообщением «Ошибка».
